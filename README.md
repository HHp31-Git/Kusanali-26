# 🌸吉祥草之音

For the Lesser Lord Kusanali. 
All right reserved.

## 🔧 技术信息

- 本mod适用版本：
-   Minecraft Java Edition 1.20.1
-   fabric-loader >=0.14.21
-   需要Fabric API

## ✨ 模组简介
- 本模组围绕 [元素反应系统] 和 专属武器 [千夜浮梦] 展开，为Minecraft带来全新的战斗机制、世界生成内容和收集内容
## 🌟 简介
- 🌿 新物品与方块
- 类别	内容
- 植物 	枣椰树（原木、树叶、树苗、木板等）、须弥蔷薇、帕蒂沙兰
- 材料 	枣椰、兰那罗之花、生长碧翡系列（碎屑→碎片→块→宝石）、终端核心
- 装备 	镀金旅团弯刀、兰那罗花冠（头盔）、虚空终端（头盔）
- 特殊 	千夜浮梦（法器）、枣椰蜜糖、哈瓦玛玛兹、《我不曾忘记》
- 装饰 	新花卉、纳西妲生日贺图（至2025）

- 🎮 元素反应系统
- 模组引入了 7 种元素状态效果：

- 反应类型	   参与元素	        效果
- 扩散	       风 + 火/冰/水	    将元素扩散到周围 1.5 格内的实体
- 蒸发	       火 + 冰	        纯伤害
- 冻结	       冰 + 水	        生成 [冻结] 效果，阻止攻击和移动
- 碎冰	       冻结 + 物理伤害	额外 4 点伤害，解除冻结
- 融化	       火 + 冰	        纯伤害
- 超载          雷 + 火	        爆炸 + 击退
- 超导  	       雷 + 冰	        伤害 + 附加 [超导] 减益效果
- 绽放          草 + 水           生成草原核
- 超绽放         雷               激发草原核造成定向伤害
- 烈绽放         火               激发草原核造成范围火伤
- 燃烧          火 + 草           触发高频率火伤
- 结晶          岩 + 火/冰/水	     生成 [结晶] 盾
- 激化          草 + 雷           下次相关元素增伤
- 超激化         激 + 雷           [超激化] 减益效果
- 蔓激化         激 + 草           [蔓激化] 减益效果

- 🗡️ 专属武器：[千夜浮梦]
- 普通攻击：

- 操作	               效果
- 左键	               连续释放 4 个魔法方阵，每个造成 7 点范围伤害（燃烧目标 +1）+ 草元素附着
- 右键蓄力（0.7 秒）	   180° 扇形重击，造成 10 点范围伤害（燃烧目标 +1）+ 草元素附着

- 技能系统：

- 默认按键	  技能名称	冷却	         效果
- R	      心景幻成	30 秒	     30 格半径内所有敌对生物持续受到魔法伤害 + 草元素附着
- G	      所识遍记	5 秒 / 3 秒   扇形锁定攻击 + 采集周围植物 + 附加蕴种印效果 + 草元素附着

- 🛒 交易系统
- 流浪商人新增交易:
- 2 绿宝石 -> 1 枣椰
- 2 绿宝石 -> 1 枣椰树苗
- 4 绿宝石 -> 1 帕蒂沙兰
- 1 绿宝石 -> 1 须弥蔷薇
- 1 绿宝石 -> 1 生长碧翡屑
- 3 绿宝石 -> 1 生长碧翡碎片

- 🪖  特殊装备与附魔:
- 物品	          效果
- 虚空终端	      佩戴后获得伪夜视效果
- 兰那罗花冠	      佩戴后获得幸运效果
- 旅团弯刀          更优秀的铁制武器
- 元素附魔          宝藏附魔，可用于剑、斧、弓

- 🌍 世界生成：
- 新植物:

- 名称	            生成位置	    说明
- 枣椰树         	繁茂恶地	    新的树木种类，可获取木材、果实
- 须弥蔷薇        	主世界全境	可用于合成或装饰
- 帕蒂沙兰        	丛林、繁华森林	可用于合成或装饰

- 新战利品:

- 物品	            获取方式	                        概率
- 《我从未遗忘》唱片	丛林神庙、沉船、合成	            20%
- 兰那罗之花	        丛林神庙、沉船、末地城	            30%
- 生长碧翡系列	    丛林神庙、沉船、末地、合成、种植、交易	20%~80%

- 🧟 生物特性
- 名称       新特性
- 烈焰人 	自带永久火元素附着
- 岩浆怪 	自带永久火元素附着
- 炽足兽 	自带永久火元素附着
- 铁傀儡 	自带永久岩元素附着
- 雪傀儡  	自带永久冰元素附着
- 史莱姆     自带随机元素附着，分裂后继承元素效果
- 女巫       射出的箭随机附带元素效果
